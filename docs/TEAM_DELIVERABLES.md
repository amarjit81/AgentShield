# AgentShield — Four-Person Presentation Split

Use this order for an approximately 8–9 minute presentation, allowing extra time
for live demo clicks. This divides speaking and demonstration responsibilities;
it does not assign historical authorship of the code.

| Speaker | Deliverable | Reading file |
|---|---|---|
| You | Problem, architecture and dashboard | [Part 1](presentation/01_YOU_OVERVIEW_AND_DASHBOARD.md) |
| Avnish | Authentication, roles and agent permissions | [Part 2](presentation/02_AVNISH_AUTHENTICATION_AND_AGENTS.md) |
| Deepanjan | Validation, policy and approval snapshots | [Part 3](presentation/03_DEEPANJAN_POLICY_AND_APPROVALS.md) |
| Sameer | Execution integrity, database, audit and verification | [Part 4](presentation/04_SAMEER_EXECUTION_STORAGE_AND_TESTING.md) |

Each file contains speaking content, a demo moment, likely questions, code to
recognize and a handoff or closing line. Read it to understand your part, then
explain it in your own words.

Rehearse together: You introduce the screen; Avnish demonstrates agent access
denials; Deepanjan creates and approves an INR 8,000 request; Sameer uses that
same request to demonstrate execution integrity and replay. Keep User and Manager
in separate browser contexts.

Shared references: [Project overview](PROJECT_OVERVIEW.md),
[setup and demo walkthrough](PRESENTATION_WALKTHROUGH.md), and
[technical implementation guide](IMPLEMENTATION_GUIDE.md).
